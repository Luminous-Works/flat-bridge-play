# Flat Bridge

A River Mumma tale for a seated, hands-only AR headset (WebXR), set at the Flat Bridge on the Rio Cobre, Bog Walk, Jamaica.

You are Samuel, the carriage driver. Montague orders you to fetch the gold from the river. Heed Samuel's warnings, or the river takes it all back.

**Play:** https://luminous-works.github.io/flat-bridge-play/

- **Meta Quest:** open the link in the Quest Browser with hand tracking on, press Enter XR, and pinch the gold. Pinch the carriage lamp to walk away.
- **Computer:** press Enter XR (a virtual headset opens), then click the gold. Click the lamp to leave. Headphones help.

This repository holds the built game only. Built with the Immersive Web SDK.
